# Evidencias del proyecto

Las capturas originales se guardan por fase y luego se insertan en el informe
final con una explicación breve de qué demuestran.

Estructura recomendada:

```text
evidencias/
├── fase1/
├── fase2/
├── fase3/
├── fase4/
├── fase5/
├── fase6/
├── fase7/
├── fase8/
└── fase9/
```

Los nombres exactos y responsables están definidos en cada archivo
`avances/faseN.md`.

Reglas:

- Mostrar el comando, resultado, nodo y fecha/hora cuando sea importante.
- No mostrar contraseñas, claves Tailscale, correos privados ni tokens.
- Usar `-p` interactivo; nunca `-pCONTRASEÑA` en una captura.
- Conservar la imagen original; no pegarla únicamente en Word/Google Docs.
- Añadir debajo de cada imagen una frase: acción, esperado y obtenido.
- Si una captura contiene un secreto, descartarla, rotar el secreto y repetirla.
